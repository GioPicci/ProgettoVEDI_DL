# UNICT-VEDI POI Detection & Classification con DINOv3 e Distillazione WSOL

Progetto accademico per il corso di Deep Learning / Computer Vision incentrato sulla rilevazione e classificazione di Punti di Interesse (Point of Interest - POI) sul dataset egocentrico **UNICT-VEDI**, ambientato nel complesso monumentale del Monastero dei Benedettini di Catania (57 classi di elementi architettonici e decorativi).

Il progetto esplora il paradigma della **Weakly-Supervised Object Localization (WSOL)**: a partire dalle sole etichette di classe dell'immagine, vengono generate pseudo-annotazioni spaziali (bounding box) sfruttando le feature self-supervised di **DINOv3 (ViT-S/16)** per distillare un rilevatore compatto real-time (**YOLOv8n**) senza l'impiego di coordinate supervisionate manuali.

## 🏛️ Architettura e Pipeline

```
[ Immagine Egocentrica ]
          │
          ▼
┌────────────────────────────────────────┐
│      DINOv3 ViT-S/16 Backbone          │  (Feature extraction auto-supervisionata)
└──────────────────┬─────────────────────┘
                   │
         ┌─────────┴─────────┐
         ▼                   ▼
┌──────────────────┐  ┌──────────────────────────────────┐
│  Linear Probing  │  │   DINO Object Detector (DETR)    │
│  Classificatore  │  │   Multi-scale + Transformer Dec. │
└────────┬─────────┘  └──────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│      WSOL Heatmap & CAM Analysis       │  (Linear-CAM, Attention, Eigen-CAM, Grad-CAM)
└──────────────────┬─────────────────────┘
                   │
                   ▼ (Pseudo-Bounding Box Generation)
┌────────────────────────────────────────┐
│    Distillazione Studente YOLOv8n      │  (Addestramento senza bbox manuali)
└──────────────────┬─────────────────────┘
                   │
                   ▼
┌────────────────────────────────────────┐
│      Sample Efficiency Benchmark       │  (Confronto curve 1%...100% vs Distillato)
└────────────────────────────────────────┘
```

1. **Backbone DINOv3**: modello Vision Transformer (`facebook/dinov3-vits16-pretrain-lvd1689m`) congelato o con fine-tuning selettivo.
2. **Classificatore & Linear Probing**: classificazione a 57 classi con mappatura naturale dei POI.
3. **WSOL Pseudo-Labeling**: estrazione di mappe di attivazione (Linear-CAM) per stimare la posizione e scala dei POI da sole label immagine.
4. **Distillazione su YOLOv8n**: dataset pseudo-etichettato per addestrare uno studente leggero ed efficiente per inferenza edge/egocentrica.
5. **Sample Efficiency**: studio empirico su quote progressive ($1\% \dots 100\%$) di ground truth per quantificare il valore di annotazione risparmiato (breakeven a $1.43\%$ di GT manuale e $61.79\%$ capacity retention complessiva).

## ⚙️ Requisiti ed Esecuzione

### Prerequisiti
- Python 3.12
- GPU con supporto CUDA (es. NVIDIA RTX 2060 o superiore)
- PyTorch $\ge$ 2.13 con CUDA 12.6, `transformers` $\ge$ 5.x, `ultralytics`, `torchmetrics`

### Esecuzione della Pipeline
I comandi vanno eseguiti dalla radice della repository:

1. **Addestramento Classificatore DINOv3**:
   ```bash
   python train_classification_dinov3.py
   ```
2. **Benchmark dei metodi WSOL**:
   ```bash
   python evaluate_wsol_detection_v2.py
   ```
3. **Generazione Pseudo-Label e Distillazione YOLO**:
   ```bash
   python autogenerate_yolo_dataset.py
   ```
4. **Addestramento e Valutazione Studente YOLO**:
   ```bash
   python yolo/train_yolo_autogenerated.py
   python yolo/test_yolo_autogenerated.py
   ```
5. **Esperimenti di Sample Efficiency**:
   ```bash
   python yolo/train_for_sample_efficiency.py
   python yolo/test_for_sample_efficiency.py
   ```

## 📊 Principali Risultati
- **Classificazione DINOv3 ViT-S/16 (Linear Probing)**: Accuratezza Top-1 del $96.88\%$ sul validation set.
- **Student YOLOv8n (Distillazione WSOL)**: mAP@50 del $37.39\%$.
- **Breakeven Sample Efficiency**: La distillazione non supervisionata a livello di coordinate equivale all'$1.43\%$ di annotazioni manuali ($25.4$ ore di annotazione risparmiate).
- **Capacity Retention**: $61.79\%$ complessiva, con un picco del $63.60\%$ nel Tier Macro (elementi architettonici medi) e dell'$84.14\%$ nel Tier Full-Frame.
